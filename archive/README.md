# 旧版课程与迁移说明

本仓库曾按照学习对话顺序形成一套 00～13 章的压缩型知识提纲，以及旧课号 1～75 的映射。2026-10-12 开始重构为“以完整 Mini Coding Agent 产品为终点”的中文教材。

**旧文档没有从 Git 历史中消失**：可在 GitHub 先前的分支和提交中查看。特别是 `textbook/expanded-foundations-20261012` 分支和对应的首批教材 PR。

旧版提纲的问题并不是概念错误，而是更适合复习、不适合无先前聊天背景的新手独立阅读。新版按知识依赖设计，并在最终必修课程包含 FastAPI + React 产品开发。
